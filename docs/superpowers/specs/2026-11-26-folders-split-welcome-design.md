# 도시별 자동 나누기 + 폴더, 처음 사용법 화면 — 짧은 설계

작성일: 2026-11-26 · 상태: 사용자 승인("다해주고 만들어줘")

## 1. 도시별 자동 나누기와 폴더

**왜:** 여러 도시를 다녀온 여행을 "일본 여행" 같은 폴더 하나로 묶고, 그 안에서 "오사카 11/10–12", "도쿄 11/13–15"처럼 도시별로 정리하고 싶다. 날짜를 직접 나누는 수고는 없애고 싶다(사용자).

**동작**
- 새 정리에서 날짜를 고르면, 사진 위치를 보고 **도시가 2곳 이상**이면 "도시별로 나눌까요?"를 제안한다. 구성은 폴더 이름과 도시별 날짜 목록이고, 버튼은 [나눠서 정리] / [하나로 정리]이다.
- **나누는 규칙(빌더 판단):** 하루 단위로, 그날 위치가 있는 사진이 가장 많은 도시를 그날의 도시로 정한다. 연속된 같은 도시의 날을 한 구간으로 묶는다. 위치 사진이 없는 날은 앞 구간에 붙인다(첫날이면 다음 구간). 하루짜리 구간이나 사진이 3장 미만인 구간은 사진이 더 많은 이웃 구간에 합친다. 합친 뒤에도 2구간 이상일 때만 제안한다.
- **폴더 이름:** 모든 구간이 한 나라면 "[나라] 여행"(예: "일본 여행", 언어별), 아니면 도시 이름을 이어 붙인 여행 이름(기존 규칙). 직접 고칠 수 있다.
- **구간 이름:** 도시 이름(예: "오사카"). 목록에는 날짜가 함께 보인다.
- **정리 목록:** 폴더는 한 줄로 보이고, 누르면 폴더 안 구간 목록이 열린다. 각 구간은 지금의 정리와 똑같이 동작한다(묶음, 스와이프, 결과). 폴더를 지우면 안의 정리도 지운다(사진은 안 지움).
- **사진 앱(사용자 승인, 제 추천):** 구간의 결과 화면에서 앨범을 만들면 사진 앱의 "[폴더 이름]" 폴더 안에 "[구간 이름] 베스트"/"스크린샷" 앨범을 만든다. 폴더가 없으면 만들고, 있으면 그 안에 넣는다.
- **첫 버전에서 뺌:** 폴더를 직접 만들거나 기존 정리를 폴더로 옮기는 기능.

**방식:** 핵심 로직(하루별 도시 판단과 구간 만들기)은 `TripPickCore`에 넣고 테스트로 검증한다. 도시 이름은 기존 애플 지도 조회를 재사용한다(새로 보내는 정보는 같은 종류, 장소 좌표뿐). 폴더는 SwiftData에 `FolderRecord`를 추가하고, `TripRecord`에 선택적 폴더 연결을 둔다. 사진 앱 폴더는 PhotoKit `PHCollectionList`로 만든다.

## 2. 처음 실행할 때 사용법 화면

**동작:** 처음 설치 후 한 번만, 사진 접근 허용 화면보다 먼저 애플 "새로운 기능" 스타일의 화면을 보여 준다. 구성은 큰 제목 "BestCut에 오신 것을 환영합니다", 아이콘과 제목, 한 줄 설명으로 된 행 4개(비슷한 사진 묶기 / 흔들림·어두움 표시 / 스와이프로 고르기 / 사진은 iPhone 밖으로 나가지 않음), 그리고 하단 "계속" 버튼이다. 설정에 "사용법 보기"를 넣어 다시 볼 수 있게 한다. 네 언어로 번역한다.

## 하지 않을 것
- 폴더 안에 폴더 넣기
- 폴더 단위로 한꺼번에 결과·삭제하기(구간별로 한다)
