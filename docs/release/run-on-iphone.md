# 내 iPhone에서 BestCut 실행하기 (개발자 계정 없이)

Apple Developer Program에 가입하지 않아도, 무료 Apple ID로 본인 iPhone에 설치해 쓸 수 있습니다. 다만 **7일마다 다시 설치해야** 합니다(무료 계정의 제한).

1. Xcode에서 `TripPick.xcodeproj`를 엽니다.
2. Xcode 메뉴 **Settings → Accounts**에서 `+`를 눌러 본인 Apple ID로 로그인합니다.
3. 왼쪽에서 **TripPick** 프로젝트 → **TripPick** 타깃 → **Signing & Capabilities**를 엽니다.
4. **Team**에서 "(본인 이름) (Personal Team)"을 고릅니다.
5. **Bundle Identifier**가 다른 사람과 겹치면 오류가 납니다. `com.trippick.app`을 `com.(본인영문이름).trippick`처럼 바꿔 주세요.
6. iPhone을 케이블로 Mac에 연결하고, iPhone에서 "이 컴퓨터를 신뢰"를 누릅니다.
7. iPhone **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜고 재시동합니다(처음 한 번만).
8. Xcode 위쪽 기기 목록에서 본인 iPhone을 고르고 ▶︎(Run)를 누릅니다.
9. 처음 실행 때 "신뢰하지 않는 개발자" 안내가 나오면, iPhone **설정 → 일반 → VPN 및 기기 관리**에서 본인 Apple ID를 눌러 **신뢰**합니다.

7일이 지나 앱이 열리지 않으면 8번만 다시 하면 됩니다. 정리 기록은 앱을 지우지 않는 한 남아 있습니다.

## 실제 사진으로 확인하면 좋은 것

시뮬레이터에서는 애플의 사진 분석 기능(Vision)이 동작하지 않아, 비슷한 사진 묶기를 간단한 대체 방식으로만 확인했습니다. 실제 iPhone에서 아래를 꼭 확인해 주세요.

- 같은 장면을 연달아 찍은 사진이 한 묶음으로 잘 묶이는지
- 다른 장면이 한 묶음에 섞이지 않는지
- 흔들린 사진, 어두운 사진, 눈 감은 사진 표시가 맞는지
- 추천(별) 사진이 실제로 잘 나온 사진인지

맞지 않으면 어떤 사진이 어떻게 틀렸는지 알려 주세요. 기준값을 조정하겠습니다.

## App Store 스크린샷 찍기 (개발자 계정 가입 후)

App Store에는 6.9인치 화면(1320×2868, 예: iPhone 18 Pro Max) 스크린샷이 꼭 필요합니다. 실제 여행 사진으로 찍어야 보기 좋으니, 본인 iPhone(또는 iPhone 18 Pro Max 시뮬레이터)에서 아래 네 화면을 찍어 주세요.

1. 여행 홈(분류별 개수와 진행률)
2. 비슷한 사진 묶음(추천 별 표시가 보이게)
3. 스와이프 화면
4. 결과 요약("1,284 → 212"처럼 숫자가 큰 여행으로)

시뮬레이터에서 찍을 때는 `xcrun simctl io booted screenshot 파일이름.png` 명령을 씁니다. 언어별(한국어, 영어, 일본어) 화면은 iPhone 설정 → 앱 → BestCut → 언어에서 바꿀 수 있습니다.
